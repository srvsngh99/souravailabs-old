To use this template:

1. Open your Google Doc and use **File -> Share -> Publish to web**.
2. Copy the published URL and set it in `embed_url`.
3. Keep this page as `draft: false` when ready.

This renders the document in an inline reader frame and avoids publishing raw `.docx` files.
